# Protótipo — LUNA

Protótipo navegável da landing page da **LUNA, Empresa Júnior de Computação da UEPB**.

**Ver online:** https://laryssa-finizola.github.io/prototipo-luna/

- É um arquivo só (`index.html`), sem dependências: abre direto no navegador, inclusive offline.
- Textos entre `[colchetes]` e imagens hachuradas são provisórios.
- O formulário de contato é demonstrativo: nada é enviado.
- A página pede para não ser indexada por buscadores (`noindex`), para não competir com o site oficial.
